# ことばクエスト ver1.2.1｜PC・ブラウザ画像整理・軽量化版

## 起動方法
ZIPを「すべて展開」し、`START_HERE.html` をダブルクリックしてください。
マイク等はブラウザの安全上の制約により HTTPS/localhost が必要になる場合があります。

## 軽量化した箇所
- PCでは写字・見写しを「なぞり練習」として提供するため、未使用の旧OCRエンジン、JLect/漢字画数辞書、Tesseract WASMを配布から除外しました。**Android版には適用しません。**
- しばバーガーは本体と共有するThree.jsを読み込み、重複するGLB・エンジンファイルを削除。元の柴犬3Dモデル（`shiba-inu.glb`）は本体側に保持しています。
- 使用していない旧モジュール式3Dコード、ビルド用コード、開発テスト、歴代バージョンの資料を配布物から除外しました。
- Web公開時のService Workerは基本画面のHTML・スクリプト・CSSを先にキャッシュし、3Dや画像・音源は必要になったときに取得・キャッシュします。3Dなどのオフライン利用には一度アクセスする必要があります。

## 維持したもの
- しばバーガーR4完全差し替え版／猫パズル／ピクトグラム3D、元の3Dモデル・3D描画
- ver1.2.1のトレーニング、問題データ、学習記録、熟練度、音量設定、クレジット
- 通常のブラウザ起動 (`file://`) と `START_PC.bat` によるPCローカルサーバー起動

## 差し替え適用時の注意
既存のver1.2.1 PC軽量化版をバックアップし、差し替えZIPを同じフォルダーに上書きしてください。画像の旧フォルダーは上書きだけでは消えません。上書き後に `CLEANUP_MOVED_IMAGES.bat` を実行すると、対応表とSHA-256で内容を照合した旧画像だけを削除します。
新しいフォルダー一覧は `README_画像整理_ver1.2.1.md`、旧→新パスの一覧は `IMAGE_RELOCATION_MANIFEST.json` を参照してください。

## ver1.2.1 スクリプト・CSS整理版

JS・CSSを用途別フォルダーへ移動しました。編集の際は `docs/スクリプト構成と編集ガイド.md` と `docs/スクリプト役割一覧.md`、`docs/スクリプト読込順.md` を参照してください。

従来の学習記録・ゲーム内容はそのままです。差し替え後は `CLEANUP_MOVED_SCRIPTS.bat` を実行して、移動済みの旧JS・CSSを安全に削除できます。
