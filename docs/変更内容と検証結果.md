# ことばクエスト ver1.2.1 PC｜コード整理の変更内容と検証結果

## 実施したこと

- JavaScriptとCSSを用途別に79ファイル移動（旧ファイルの単純なコピーではなく参照コードも更新）。
- メインメニュー・3D・神経衰弱・猫パズル・朗読・しばバーガーなど13画面のJS/CSS参照を更新。
- CSSが参照する背景画像3か所の相対パスを移動先に合わせて修正。
- オフラインキャッシュの参照先とキャッシュ識別名を更新。`service-worker.js` はルートに保持。
- スクリプト・CSS先頭の日本語説明と、主要な処理39か所への日本語注記を追加。
- 旧ファイルを削除する際は旧ファイルの元版SHA-256と、新ファイルの期待SHA-256を両方確認。
- 柴犬・猫の3Dモデル、画像・効果音・BGM、学習記録の保存キーには変更を加えていません。

## 実施できた検証

- JavaScriptの構文チェック（外部ライブラリを除くすべての自作JS、3D埋込スクリプトを含む）。
- Node.jsによるHTML・CSS・service-worker.jsの静的参照279件の存在確認。
- 画像221点と画像参照186件の整合性確認（前回画像整理版と同一画像）。
- PC起動HTML、メインHTML、学習・ゲーム用JS・CSS、3DスクリプトのHTTP取得成功。
- 画像整理版に差し替えZIPを適用し、安全に旧79ファイルを除いた状態と完全版の全ファイルが一致することを検証。
- ZIP内のCRC検査。

## 未検証・利用時の注意

- 自動ブラウザ実行はこの環境で時間切れになったため、3D描画・マイク・音声・画面操作の実機動作は未確認です。
- 音声認識にはブラウザごとの制約があり、マイク権限などの設定が必要な場合があります。
- 差し替え用ZIPは **前回のver1.2.1「画像整理済み完全版」専用** です。バックアップ後に上書きし、`CLEANUP_MOVED_SCRIPTS.bat` を実行してください。旧ファイルが更新・改変済みなら削除は保留されます。
- テスト用Node.jsはアプリ自体の起動には不要です。
