# ことばクエスト ver1.2.1 PC｜スクリプト・コード整理の説明

この版は、前回の画像整理版を元にしています。ゲーム内容、3Dモデル、音声素材、学習記録の保存方法は変更していません。

## まず起動するファイル

- `START_HERE.html` を開いてください。そこから `index.html` や各ゲームを起動します。
- `index.html` と `service-worker.js` はルート直下に残します。後者を移すとオフラインキャッシュの適用範囲が変わるためです。

## 新しいフォルダー

- `scripts/application/`：メインの出題・画面・記録（`app.js`）。
- `scripts/system/`：プロフィール、画面表示、日々の連続記録。
- `scripts/audio/`：BGM、効果音、読み上げ設定。
- `scripts/learning/`：熟練度、学習モード、自動学習調整。
- `scripts/training/`：失語症、発音、写字、個別課題の表示。
- `scripts/questions/`：問題文、選択肢、個別ヒント。
- `scripts/conversation/`：会話、AI回答の関連処理。
- `scripts/games/`：猫パズル、ダンジョン、神経衰弱、しばバーガーの記録連携など。
- `scripts/3d/`：PC用3D描画とモデルの埋め込みデータ。
- `scripts/ui/`：画面共通テーマの同期。
- `styles/`：上記と同じように、基本画面・練習・ゲーム・UIごとにCSSを分類。
- `shiba-burger-r4/scripts/` と `shiba-burger-r4/styles/`：独立版しばバーガーR4のソース。
- `vendor/three/` と `fontawesome/`：外部ライブラリ。ライセンスを保持し、移動していません。

## 編集時に壊れやすいポイント

1. **JSの読み込み順を変えない**：`app.js` より先に共通音声や学習設定を読み込み、問題データは元のタイミングで拡張しています。画面ごとの実際の順番は `スクリプト読込順.md` を参照してください。
2. **JS中の相対画像パスは多くの場合HTML基準**：`fetch('images/…')` や画像の `src='images/…'` は実行中のページのURL基準です。JSを `scripts/` へ移したことだけを理由に `../../images/` に書き換えてはいけません。
3. **CSS中の `url(...)` はCSSファイル基準**：そのため `style.css`・`veta19-dialogue.css`・しばバーガーCSSの画像パスは移動先に合わせて直しました。
4. **R4独立版の柴犬**：`shiba-burger-r4/index.html` は独立した1ゲームです。`scene3d-classic.js` 内の `../shiba-inu.glb` はHTML基準のため変更していません。
5. **学習記録はキーを変えない**：`user-profile.js`、`difficulty-veta11.js`、`unified-learning-veta1.js`、各ゲームの integration が同じ利用者に記録します。
6. **オフライン公開**：JS・CSSを追加した場合は `service-worker.js` の `APP_SHELL` とキャッシュ名を確認します。
7. **外部ライブラリ・3Dモデル**：`vendor/three/` と `scripts/3d/pc-models-inline.js` の内部を改変・削除しないでください。

## 修正したい場所の例

- 問題やヒントを変える → `scripts/questions/`
- マイクの反応を変える → `scripts/application/app.js`、`scripts/training/aphasia-modes.js`、`scripts/training/pronunciation-training.js`
- 正解・不正解の効果音を調整 → `scripts/audio/`
- しばバーガーの出題 → `shiba-burger-r4/scripts/orders-classic.js`
- しばバーガーの登場人物・位置 → `shiba-burger-r4/scripts/scene3d-classic.js`
- しばバーガーの画面 → `shiba-burger-r4/styles/style.css`
- 猫のパズル → `scripts/games/cat-word-puzzle.js`
- 色や文字サイズ → `styles/base/` と `styles/ui/`

## 確認コマンド

Node.jsがインストールされていれば、次の検査ができます。

```bat
node tools\verify-script-paths.cjs
node tools\verify-image-paths.cjs
```

Windowsでは `CHECK_SCRIPT_FILES.bat` で両方を実行できます（Node.jsが必要です）。

移行元の ver1.2.1 画像整理版に差し替えた場合、旧JS/CSSを削除するために `CLEANUP_MOVED_SCRIPTS.bat` を実行してください。旧ファイルはハッシュ一致を確認してから削除するため、利用者が変更したファイルは残ります。
